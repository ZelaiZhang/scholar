# 指导实验设计

## 输入

- 读取已人工选定的 Idea、研究问题、证据账本和可用公开数据说明。
- 获取资源约束，但不连接集群或训练环境。

## 流程

1. 检查输入是否含可识别健康信息；发现后停止。
2. 把研究假设转成可观察变量、主要终点和预先声明的失败判据。
3. 设计数据划分，重点检查患者级、来源级、时间级和提示模板泄漏。
4. 选择强基线、负对照、关键消融、主辅指标、置信区间和统计检验。
5. 记录超参数选择规则、随机性、资源估计、复现要求和伦理限制。
6. 写入 `05-experiment-design.md`，列出必须由人工确认的设计决策。
7. 只有下列质量门禁全部通过且设计决策已由研究者确认后，才在文件末尾写入 `<!-- research-os:stage=design-complete -->`；否则移除该标记并禁止进入结果阶段。

## 硬边界

- 不得运行训练、微调、量化、强化学习、集群提交或 GPU 实验命令。
- 只给设计、伪代码、命令建议或检查清单；实际执行留在独立实验仓库。

## 质量门禁

- 禁止编造数据规模、预期提升、统计功效或已有结果。
- 区分探索性分析与验证性分析，避免测试集调参。
- 医疗场景必须说明亚组、公平性、分布偏移和临床外推限制。
- 在人工确认前不把设计写成既定事实。
