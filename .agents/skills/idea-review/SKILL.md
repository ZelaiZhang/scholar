# 反向审查研究 Idea

## 输入

- 读取 `00-research-brief.md`、`02-evidence-ledger.yaml`、`03-literature-review.md` 和候选想法。
- 在新颖性依赖近期文献时，记录检索日期、查询式和覆盖范围。

## 流程

1. 检查输入是否含可识别健康信息；发现后停止。
2. 把每个 Idea 写成“科学问题—可证伪假设—候选贡献—验证方式”。
3. 主动寻找最接近工作、反例、不可获得数据、不可比基线和算力风险。
4. 检查是否只是更换模型、数据集、提示词或堆叠模块。
5. 从新颖性、科学价值、可执行性、评测可信度和医疗安全五个维度排序。
6. 写入 `04-idea-candidates.md`，给出继续、补证据或放弃建议，交由人工决定。
7. 只有下列质量门禁全部通过且研究者已记录选择、理由和放弃条件后，才在文件末尾写入 `<!-- research-os:stage=idea-complete -->`；否则移除该标记。

## 质量门禁

- 禁止编造近期论文、创新空白或数据可获得性。
- 没有充分检索时使用“候选空白”，不得使用“首次提出”。
- 每个高优先级 Idea 必须有最强反对意见和失败判据。
- 不把模型性能改善自动解释为临床价值。
