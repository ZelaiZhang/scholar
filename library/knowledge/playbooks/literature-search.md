# 文献检索手册

## 输入

研究问题、概念同义词、目标人群/任务、方法族、日期范围和可访问数据库。

## 动作

1. 先检索综述/规范与奠基论文，再检索最新反例和负结果。
2. 在 `01-search-log.md` 记录数据库、完整检索式、日期、纳排和未获取全文。
3. 用 `paper-intake` 一次原子登记清单；用 `paper-deep-read` 区分摘要与全文。
4. 新颖性结论必须保存查询式、最近工作、差异和未解决重叠。

## 失败判据

只有标题或摘要、无法定位原文、检索只包含支持证据、时间/数据库范围不明时，不宣称系统综述或新颖性成立。

## 交给技能的问题

向 `literature-synthesis` 提供“哪些设置可比、主要冲突、反例和下一轮查询”，不要要求它凭文献数量选赢家。
