# Projects

每个课题由 `research-os new-project` 创建为独立目录。不要直接复制其他课题目录，以免遗留错误的标题、证据和来源。

标准阶段文件：

```text
00-research-brief.md
01-search-log.md
02-evidence-ledger.yaml
03-literature-review.md
04-idea-candidates.md
05-experiment-design.md
06-result-analysis.md
writing/
reviews/
artifacts/
```

数字前缀代表推荐顺序，不表示系统自动批准进入下一阶段。Idea、论文事实和最终投稿内容始终需要人工确认。
