## 2. 三个问题及对照

| 问题 | 比较方式 | 需要保持相同 | 失败或收缩条件 |
|---|---|---|---|
| 树与条件级证据是否各有作用？ | 自由式 CoT + 同准则；树 + 原历史；树 + 结构化证据 | 判断模型、知识范围、已观察证据、输出定义与预算 | 共享准则的自由式方法达到相同表现，或差异只由知识量解释 |
| 最终复判是否超出额外计算的效果？ | 各方法无复算；各方法同证据末端普通复算；现有树最终复判 | 完整已观察历史、信息权限、累计计算与停止规则 | 普通复算达到相同收益，应将复判定位为实用控制而非独有贡献 |
| 错误排除改善是否损害正确候选？ | 逐候选树配对的错→对/对→错，分别按正负类与病例组分析 | 同病例、同树、同标签、同证据前缀 | 正类错误反转抵消排除收益，或净改善只来自个别病例/失败剔除 |

以上比较均为 hypothesis / proposed protocol，不宣称现有基线已经公平。

## 3. 最小实验矩阵

建议先采用一个已用模型和冻结知识版本，避免过早增加模型、算法或大量参数。

| 条件 | 程序树 | 条件级结构化证据 | 末端额外判断 |
|---|---|---|---|
| A：同准则自由式 CoT | 无 | 无，完整源回答可见 | 无 |
| B：同准则自由式 CoT + 普通复算 | 无 | 无，完整源回答可见 | 一次普通独立判断 |
| C：现有树去除证据组织 | 有 | 无，但不删除原始证据 | 无 |
| D：现有树与证据，复判前 | 有 | 有 | 无 |
| E：D + 普通复算 | 有 | 有 | 同证据、普通独立判断 |
| F：现有完整系统 | 有 | 有 | 研究者已有最终复判 |

若 E 与 F 其实是同一实现，应合并而非制造虚假方法差异。各条件额外判断的次数和真实 token/延迟都计入成本。先固定一份对话回放隔离判断机制；之后再进行交互式运行检验提问策略，不把不同回答获得的信息量混入前者结论。

不要求把新的 Judge/Planner 分离提示词加入上述矩阵；它是工程修复候选。JSON/等信息文本/去重开关只在具体故障需要定位时做附录诊断，不能代替主比较。

## 4. 输入控制与标签泄漏

- 固定回放：所有判断条件获取同一个可观察前缀，包含截至该时刻已获得的回答；无未来回答或隐藏标签。
- 准则对齐：对照获取相同诊断条件和排除规则；不能用额外知识弱化对手。
- 复算输入：记录是否可见旧标签、节点状态与推理轨迹；同证据不等于同输入权限。
- 访谈实验：固定源病例/模拟器版本和信息披露规则，记录所有调用；说明病例真实或合成、模拟回答对未提及信息的处理。
- 不任意打乱病史，时间范围或有效更正需保持其语义。无损证据整合与模型摘要分开比较。
- 金标准不得用于复判提示、触发、示例选择或停止。ICL 示例不得来自同病例/同模板衍生组的测试记录。

## 6. 指标、正类保护与统计

建议同时报告正确树率 R+、错误树排除率 R−、BA、总体正确数，并保留原始计数。候选主终点为 BA；其选择现属探索后设计，必须在新的验证测试前冻结，不能追认过去已预注册。

正确树保护作为单独约束：不能仅以 BA 增益接受正类退化。若采用非劣性或风险阈值，界值、置信水平、功效及可接受漏判代价需由研究者和领域专家确认，当前不生成未经根据的数值。

分别报告正类和负类的保持正确、保持错误、错→对和对→错；输出非法、超时、弃答和证据不足单列。按冻结政策计入分母，不能仅对成功项报告主结果。另有最终病例级任务时，单独评价完整输出，不从候选 BA 推出病例准确率。

病例分组齐全后，优先采用按源组的配对区间/重抽样分析；相互独立的二分类项且满足检验条件时，才考虑配对 McNemar。多随机运行应说明嵌套层级，不能把重复种子当额外患者。当前没有逐例数据，不计算 p 值、功效或区间。

## 7. 改判机制审核

在不发送真实病例内容的前提下，研究者可在独立实验仓库内完成匿名化人工审核。审核者应能对照条件、证据与预测，但尽可能隐藏方法身份。

候选错误分类：问答错配、否定/时间范围错误、证据不足误判、条件/阈值漏算或计重、流程停止/回退、原结论锚定、复判新增误排除。允许其他/无法判定，不能强迫所有案例符合论文叙事。

对所有改判分别审查：依据的是新证据、重读旧证据、规则重算还是无可追溯依据。审核纠错和错误反转，以及失败路径；记录评审者资格、一致性和分歧处理，不虚构临床专家参与。
