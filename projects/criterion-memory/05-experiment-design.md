## 1. 假设与可识别效果

- H01：固定输入、模型、知识和预算时，条件证据记忆改善诊断质量，并减少关键证据遗漏。
- RQ2：明确修订和依赖失效处理能改善迟到/更正证据后的预测；不应提高没有有效更正时的误反转率。
- H02：学习式管理器可优于确定性条件策略；若否，保留训练免除路线，不为使用 RL 强行增加复杂度。
- 研究对象是离线模拟。不把多标签分类或证据指标解释为临床诊断能力。

## 2. 数据准备与标签

候选公开资源：PsyCoTalk（固定对话回放）和 MentalBench（候选外部静态病例复验）。来源/阅读范围见 F02/F07 和文献矩阵；**许可与数据内容未核实，不代表已取得可用数据**。
私人医保/病历只登记去标识的元数据说明；不得把病例原文放入此库或公开 Git 分支。

启动前必须完成：许可与改编/再分发条件、知识版本、疾病覆盖、对话长度、病例组键、最终标签来源、条件证据是否足以复核、受限数据处理环境。禁止从诊断字段或模板名泄漏答案给模型。
没有病例组键时先恢复可审计的同源关系；无法可靠恢复则停止验证性结论，报告此限制。
如果只得到模拟/自述标签，称为数据集标签一致性，不称为临床金标准。

### 金标准的最小结构

在独立受控数据环境为每个源病例标注：

- 病例/来源组 ID（去标识），所有改写/对话/扰动共享组；最终任务标签，或明确无法判定；
- 条件 ID、关联文本 span、支持/反对方向、实际事件时间、信息出现轮次；
- unknown、冲突和经确认的更正/撤回关系；单纯新时间段事件不是旧证据撤回；
- 关键条件集合（盲于方法输出，由临床专家依据任务定义预定）；
- 在每个前缀上**已出现**的可判断标签集合，不能把未来症状当作当前可知证据。

优先两名具备相应知识的标注者独立标注，再仲裁。报告条件状态一致率与 kappa/alpha（按变量类型选择）、span 一致性和仲裁比例。LLM 可以提建议，但同一生成器不能同时制造全部病例、最终金标准与主评测结果。
标注资源不足时先做小规模可行性回放，不能宣称全面临床有效性。

## 3. 分组划分与泄漏检查

建议初始分组比例 60/20/20（训练/开发/测试），这是设计选择，不是已经完成的数据划分。
先按源病例/患者/来源组切分，再做对话生成、语序扰动或修订；同一源病例的所有变体保持在一个集合。
在条件允许时预留独立来源或时间段作为外部测试。公开基准潜在预训练污染只做审计并报告，不能声称完全排除。
知识树可使用固定的通用规则，不能使用测试病例派生的示例、标签统计或人工修正。
先查 exact/near duplicates 与模板族交叉；在检查数据内容的环境内执行，不在本库加载病例。
测试集只运行冻结方案；调参、选择基线、奖励权重与停止阈值都限训练/开发。

## 4. 两层实验以隔离因果因素

### A. 固定对话回放：主要验证

所有方法看到相同轮次输入序列、相同知识和固定诊断器，管理各自记忆。模型不能自选问题，避免问诊策略改变信息来源。
在 25%、50%、75% 和完整前缀处评估；重复检查点是同一病例簇，不能当作独立样本。
最终标签质量以完整前缀为主；前缀阶段依据已观察条件的金标准，证据不足允许 abstain。
区分直接复用既有对话与从记录生成的新回放序列，不混报。

### B. 交互式访谈：扩展验证

从冻结的合成病例世界状态提供响应；患者模拟器不因方法提示而添加未定义症状。
管理策略和问诊/停止策略分开比较；先冻结相同追问器，再评估联合策略作为探索性结果。
核查模拟器回答是否与世界状态一致；对关键样本做专家盲评，不能只看模型互评。
停止次数、重问、超时、非法状态和无答案都纳入分母。

## 5. 预算与公平性

拟议输入预算网格 B ∈ {1024, 2048, 4096, 8192} token。主预算暂取 2048，须经开发集上的输入开销/任务可行性检查后锁定；若固定指令+知识片段+新输入已超过 B，该配置记为 infeasible，不能悄悄扩大预算或删关键规则。
B 指每次诊断器调用的全部输入：系统指令、知识、当前输入、工作记忆和检索片段。保留生成 token 上限一致。
同时报告**全系统累计**输入/输出 token、管理器/抽取器/检索器调用、额外模型、外部存储大小、延迟与失败次数。若管理器可以看到完整历史，这种访问必须对基线同样开放并计费。
跨模型 token 无法直接视为同一成本；主比较在同一 tokenizer/backbone 内做，再分别报告跨模型复验。
固定解码参数与诊断提示；约束预算与预算违规率分开报告，不把不守预算的结果混入主表。

## 6. 基线与消融

| 代号 | 对照 | 要解决的混淆 |
|---|---|---|
| Full-history | 能容纳原始历史的诊断器，较高预算参考 | 估计压缩损失；不是预算公平的主对照，也不是理论上界 |
| Window | 等预算滑动窗口 | 遗忘的简单下限 |
| Summary | 等预算递归摘要，允许开发集调优 | 排除只赢弱截断方法 |
| Retrieve | BM25 + 相同 backbone 的语义/相关性重排 | 检索与状态记忆的差异；全部调用计费 |
| Structured-tree | 用户已有树或明确实现的 ProAI/PsyCoTalk 式流程，固定更新规则 | 与用户当前实验和最接近工作对照；改编需标明 |
| MHM | 全文核对后实现/复现的多头记忆 | 强训练免除通用记忆；未忠实复现只能称 adaptation |
| Intent-memory | 全文核对后的 STITCH 式意图检索 | 控制上下文语义兼容性 |
| Learned-memory | 全文核对后可复现的 Memory-R1/Folding 管理器 | 通用学习记忆；不混用更强诊断 backbone |
| CPM-rule | 本方案确定性条件策略 | 不依赖 RL 的最小方法 |
| CPM-learned | 可选学习管理策略 | 检验 H02 的额外价值 |
| Gold-evidence | 只给已观察的人工关键证据，同预算 | 分析型参考，不参加方法排名；可能仍不是完美上界 |

主对手在开发集从 Summary/Retrieve/Structured-tree/MHM/Intent-memory 的可忠实实现方案中选定并冻结；论文同时报告全部可比强基线。
学术基线若资源不足以复现，必须声明缺口；不能把提示模仿称为原算法复现。
主比较共用冻结的条件抽取器；单独报告抽取准确度，避免“更好的抽取器”被误解释为“更好的管理”。通用基线同时给一个共享抽取结果版本，排除额外证据输入的优势。

关键消融：合并 unknown/negative；去掉时间范围；去掉否定/排除条件优先级；覆盖旧记录而不保留修订历史；禁止依赖失效回退；删除 provenance；等长打乱条件关联；rule→learned。每次只改一个因素，尽量匹配输入长度和调用开销。

## 7. 扰动与负对照

- 经审核的否定、时间范围澄清、排除条件晚到、冲突后有效更正、同义改写、有限数量无关叙述；所有扰动必须重新确认世界状态和金标准。
- 对照包含无需改变判断的普通补充、不同时间段事件，以及表面写着“更正”但没有实质证据改变的语句，测错误反转。
- 自然长度主结果与压力测试分开；压力测试保留原始可用证据并注明人为增长，不能替代真实长程任务证明。
- 条件身份/关联打乱若不降低效果，检查是否答案从生成模板、标签字段或措辞泄漏。
- 在另一疾病模块、模板族或模型家族复验；迁移结果属于外推检验，不冒充临床研究。

## 8. 指标、统计与胜负规则

主要终点：**完整回放、主预算下的诊断 macro-F1 差值**（CPM-rule 对预定强基线）。拒答算未给出该标签，同时单独报告覆盖率；另报 label-set accuracy 和 per-label recall，避免靠保守少报虚增某些指标。
关键机制终点：关键已观察证据遗漏率；分母是专家指定关键证据总数，分子是压缩/检索后不能从当前可见输入恢复的数量。多证据同义集合允许有效替代，不能仅以关键词缺失判错。
辅助指标：条件四状态 macro-F1、支持/反对方向准确率、时间范围错误率、unsupported evidence rate、span 可追溯率、修订正确率、恢复延迟（轮次，含未恢复）、误反转率、风险-覆盖曲线，以及完整系统成本。
条件状态测试标签不得作为管理器输入；Gold-evidence 是独立分析条件。

统计单位为源病例组。用配对、分组 bootstrap 估计主要差值及 95% CI；重采样必须携带病例全部对话/检查点/种子，先聚合病例内指标。label-set correctness 可补充配对检验，不对非独立轮次做普通独立样本 t 检验。
唯一预声明主比较不多重扩张；其他基线、预算和亚组明确为次要/探索性，验证性次要检验用 Holm 校正。
可选学习版本至少三次训练种子；推理随机性复验至少三组种子。没有足够资源时报告种子不足，不把一条曲线当稳定增益。
样本量根据开发/试点的病例间方差、可用源病例数及目标 CI 精度决定；不能捏造统计功效。先固定样本数/停止规则，再看测试集。

H01 的继续标准：主要差值 CI 下界 > 0，并在成本匹配与关键遗漏指标上没有相反证据；这只是设计判据，非预期结果。
若仅降低 token，须在看测试前预定非劣效界值 δ 并由研究者解释其用途；不能事后把不显著称为“无损”。
H02 需要独立优于 CPM-rule 的质量-累计成本折衷；若没有，移除 RL 贡献主张。

## 9. 算力与分阶段预算

模型 checkpoint、硬件和可用时间未知。先选一个本地可运行、许可证合适的冻结 backbone；第二模型用于稳健性复验。具体名称/参数量由资源确认后固定，不预设用户有大规模 GPU。

先用训练/开发集合中约 30–50 个源病例做可行性试点（拟议数量，非实际数据规模），检查长度、标注和预算。
回放调用数粗估 = N × M × K × S，其中 N 为病例数，M 为方法数，K 为前缀/预算配置数，S 为推理种子数；另加每方法的更新/抽取/检索调用。成本 = 所有调用输入/输出 token 按相应本地耗时或实际计价求和。
示例计划：30 病例 × 6 方法 × 4 检查点 × 2 种子 = 1440 次诊断调用，**未含管理开销，也不是已执行或推荐的最终规模**。先测小试点单次开销，再估算整体时间，不凭模型名承诺训练时长。
阶段顺序：数据与树审计 → 小回放 → 强规则基线 → 冻结验证协议 → 可选独立实验库 RL → 外部复验 → 结果解释与写作。

## 10. 复现与停止条件

每次运行固定：模型/抽取器/tokenizer 哈希、代码提交、知识版本、来源组划分、提示词哈希、预算计费规则、超参数搜索空间、奖励权重、全部种子、非法操作与失败日志。
结果导入只用去标识聚合表和来源说明；本库的 artifacts/results-manifest.yaml 只能在有真实外部产物后生成。

停止：数据许可或去标识边界不明；树无法审核；测试组泄漏；模型读取隐藏标签；自然对话没有预算压力；主改进只来自额外调用/信息；学习策略稳定性或成本无法支持 H02。
按数据可用性报告疾病、信息完整度、文本长度、语言、共病等亚组；人口学亚组只有合法且可靠标注时才做，不能推断敏感属性补标签。
限制包括合成分布、标注与抽取误差、未知预训练污染、知识版权、样本量及临床外推。本设计不构成伦理批准。
