主要待检验比较是 B−A 与 D−C；二者之差用于分析去重与表示的交互。如果 JSON 同样改善无去重条件，不能把全部收益都归因于修复去重干扰。

固定回放仅用于隔离节点判断的变化；它不能直接证明交互式访谈减少重复提问。交互评估需在冻结的病例世界中另外进行，并区分无必要的重复问题和有必要的澄清问题。
