`hypothesis / proposed study`：多轮诊断问询需要将分散在不同轮次的信息对应到明确的诊断条件，同时区分未获知、明确否定、不同时间事件和后续更正。本文拟研究在相同可见对话、准则知识与累计计算预算下，如何保留条件判断所需的信息。候选方法将证据关联到条件子要素，记录原问答定位及事件范围，通过追加式账本维护支持、反驳、未知和冲突状态，并选择保持当前程序规则状态的见证包。提问记录与判断证据分离，避免将已问过误当作证据充分；修订由独立批准工作流控制。拟在冻结前缀上分别评价提取质量和选择质量，与完整 JSON、无损整合、任务摘要、相关检索及普通额外复算比较，并单独报告反证遗漏、范围错误、正确候选保留与错误反转。**实验效果、区间和成本槽位须在新实验完成后填入。**

## 引言中更清晰的问题定义

`inference`：长历史中存在信息，不代表该信息在当前条件判断时被正确使用。只评价最终诊断或整体摘要质量，难以区分三类失败：提取阶段没有识别原文中的关键要素；选择阶段删掉了反证、时间限定或冲突另一侧；更新阶段仍沿用已被更正的旧值。这三类失败需要不同的对照和修复方式。

`hypothesis`：本研究拟把关键信息定义为能支持、反驳、澄清或更正目标条件子要素的证据，以及仍未解决的必要缺口。研究问题是这些要素在给定成本下是否正确到达判断器，而非 JSON 序列化是否优于纯文本。判断输入与提问记录分离是控制干扰的实现约束，是否产生收益仍需消融。
