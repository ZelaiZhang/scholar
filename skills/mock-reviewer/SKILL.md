# 模拟多视角审稿

## 输入

- 读取用户指定稿件、补充材料、证据账本和实验设计。
- 不读取含可识别健康信息的病例附件。

## 流程

1. 分别采用方法审稿人、统计审稿人、复现性审稿人和医疗安全审稿人视角。
2. 每条意见引用具体稿件位置、claim ID 或缺失证据，不写泛泛批评。
3. 区分致命问题、主要问题、次要问题和表述建议。
4. 对每个问题给出可验证的修复路径，同时指出不一定需要新增实验的情况。
5. 检查贡献新颖性、对照公平性、统计充分性、过度外推和伦理披露。
6. 把审稿报告写入 `reviews/`，把回应草案写入返修矩阵，交由人工选择。

## 质量门禁

- 禁止编造审稿标准、论文内容、引用或不存在的实验缺陷。
- 不因追求苛刻而要求与论文主张无关的工作。
- 对医疗风险采用保守表述，发现可识别健康信息时停止。
- 不替人工发送投稿、回复审稿人或承诺实验。
