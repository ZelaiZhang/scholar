# 结构化精读论文

## 输入

- 获取已登记的 `source_id` 和论文全文；优先使用带 `<!-- page:N -->` 标记的提取文本。
- 读取 `templates/paper-card.md`，并确认目标卡片尚未存在或已获人工覆盖许可。

## 流程

1. 检查是否出现可识别健康信息；发现后停止处理。
2. 若输入是 PDF，先运行 `python -m research_os extract-pdf` 保留页边界。
3. 按研究问题、方法、数据划分、基线、指标、结果、局限和复现信息阅读。
4. 把论文直接报告内容标为 `reported_fact`，模型解释标为 `model_inference`，保留 `researcher_note` 区域。
5. 为关键事实填写 `source_id` 与页码/章节；找不到定位时标为未核验。
6. 写入 `library/papers/<source_id>.md`，最后列出仍需人工检查的信息。

## 质量门禁

- 禁止编造缺失的页码、数值、方法细节和引用。
- 只读到摘要时显式标注“摘要范围”，不得推测全文。
- 不覆盖人工笔记或把模型推断改写成论文事实。
- 医疗论文中区分技术性能、临床效用和真实部署证据。
