# 科研周复盘

## 输入

- 读取本周 Git 变更、课题状态文件、检索日志、论文卡片、证据账本和人工笔记。
- 只统计可在工作区中核验的完成项。

## 流程

1. 检查输入是否含可识别健康信息；发现后停止。
2. 按“已完成、证据变化、被推翻假设、当前阻塞、风险”汇总本周。
3. 区分真实完成、进行中、计划和模型建议，不把计划写成成果。
4. 选择不超过三个下周关键目标，为每项给出可检查产物和停止条件。
5. 标出需要导师决策、需要补充检索和需要人工核验的事项。
6. 写入课题目录的 `reviews/weekly-YYYY-MM-DD.md`，不覆盖已有周报。

## 质量门禁

- 禁止编造阅读量、实验进展、导师意见或完成日期。
- 每项完成内容必须关联文件、提交或来源记录。
- 保留人工笔记中的主观感受，但与证据结论分开。
- 不把模型给出的优先级当成最终决定。
