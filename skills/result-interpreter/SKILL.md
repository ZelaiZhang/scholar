# 解读实验结果

## 输入

- 读取 `05-experiment-design.md`、外部实验结果、数据版本与代码提交标识。
- 不接收包含可识别健康信息的病例级结果。

## 流程

1. 核对结果来源、实验版本、样本量、运行次数和预设假设。
2. 区分主要结果、探索性结果、最佳单次运行和完整分布。
3. 检查统计意义、效应大小、置信区间、实际意义和多重比较。
4. 查找异常、选择性报告、数据泄漏、缺少对照和与设计不一致之处。
5. 分别写出“可以支持”“暂不能支持”和“需要补充”的结论。
6. 更新 `06-result-analysis.md`，把新事实关联到外部结果文件而非虚构论文来源。

## 质量门禁

- 禁止编造缺失的运行、显著性、误差条或失败原因。
- 不把相关性写成因果关系，不把小幅技术提升写成临床获益。
- 发现可识别健康信息时停止，不复制到报告。
- 保留人工解释和负结果，不能只挑选有利数据。
